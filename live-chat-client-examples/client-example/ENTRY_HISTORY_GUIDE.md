## 📖 详细使用说明

### 🔍 查询功能

#### 基本查询
1. **按直播间ID查询**
   - 在"直播间ID"输入框中输入ID
   - 点击"🔍 查询"按钮

2. **按平台筛选**
   - 选择平台（抖音/快手）
   - 点击"🔍 查询"按钮

3. **按用户昵称搜索**
   - 输入用户昵称（支持模糊匹配）
   - 点击"🔍 查询"按钮

4. **按时间范围查询**
   - 选择开始时间和结束时间
   - 点击"🔍 查询"按钮

#### 组合查询
可以同时使用多个条件进行精确筛选，例如：
- 直播间ID + 时间范围
- 平台 + 用户昵称
- 所有条件组合

#### 重置查询
点击"🔄 重置"按钮清空所有筛选条件并重新加载全部数据。

### 📊 统计数据

页面顶部显示统计卡片：
- **总记录数** - 数据库中的入场记录总数

### 📋 数据表格

表格列说明：
- ☑️ **复选框** - 用于批量选择
- **ID** - 记录唯一标识
- **平台** - 抖音/快手

### 🗑️ 删除功能

#### 单条删除
1. 找到要删除的记录
2. 点击该行的"删除"按钮
3. 确认删除操作

#### 批量删除
1. 勾选要删除的记录（或点击表头全选）
2. 点击"🗑️ 批量删除"按钮
3. 确认删除操作

---

### 📥 导出CSV

1. 设置筛选条件（可选）
2. 点击"📥 导出CSV"按钮
3. 浏览器自动下载CSV文件

**CSV文件格式：**
```csv
ID,平台,直播间ID,用户UID,用户昵称,抖音号,进入时间
1,douyin,732385677810,uid123,张三,zhangsan,2026-06-13 10:30:00
```

---

### 🧹 清理旧数据

1. 点击"🧹 清理旧数据"按钮
2. 输入要保留的天数（例如：30表示保留最近30天）
3. 确认清理操作

**注意：** 此操作不可恢复，请谨慎使用！

## 🔌 API接口

### 查询入场记录
```bash
GET /api/live-entry/query?roomId=xxx&platform=douyin&username=张三&pageNum=1&pageSize=20
```

### 获取单条记录
```bash
GET /api/live-entry/{id}
```

### 删除单条记录
```bash
DELETE /api/live-entry/{id}
```

### 批量删除
```bash
POST /api/live-entry/batch-delete
Content-Type: application/json

[1, 2, 3, 4, 5]
```

### 删除直播间所有记录
```bash
DELETE /api/live-entry/room/{roomId}
```

### 清理旧数据
```bash
POST /api/live-entry/clean-old-data?days=30
```

### 获取统计数据
```bash
GET /api/live-entry/statistics?roomId=xxx&platform=douyin
```

### 导出CSV
```bash
GET /api/live-entry/export/csv?roomId=xxx&platform=douyin
```

## 🗄️ 数据库表结构

### live_entry_history

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| platform | VARCHAR(20) | 平台标识（douyin/kuaishou） |
| room_id | VARCHAR(100) | 直播间ID |
| uid | VARCHAR(100) | 用户唯一标识 |
| username | VARCHAR(100) | 用户昵称 |
| display_id | VARCHAR(100) | 抖音号/快手号 |
| created_at | DATETIME | 进入时间 |

**索引：**
- PRIMARY KEY (`id`)
- KEY `idx_room_platform` (`room_id`, `platform`)
- KEY `idx_uid` (`uid`)

## ❓ 常见问题

### Q1: 为什么查询结果为空？

**A:** 可能的原因：
1. 筛选条件过于严格
2. 数据库中确实没有符合条件的数据
3. 时间范围设置错误

解决方法：点击"重置"按钮查看是否有数据。

### Q2: 如何快速定位某条记录？

**A:** 
1. 使用用户昵称模糊搜索
2. 使用UID精确查询
3. 缩小时间范围

### Q3: 批量删除有数量限制吗？

**A:** 理论上没有限制，但建议每次不超过1000条，避免长时间锁定数据库。

### Q4: 导出的CSV文件乱码怎么办？

**A:** CSV文件使用UTF-8编码，请使用支持UTF-8的软件打开（如Excel、Notepad++）。

### Q5: 清理旧数据会影响正在采集的数据吗？

**A:** 不会。清理操作只删除指定时间之前的记录，不影响新数据的采集。

### Q6: 可以恢复已删除的数据吗？

**A:** 不可以。删除操作是永久性的，请谨慎操作。建议定期备份重要数据。

## 🎯 最佳实践

### 1. 定期清理
- 建议每月清理一次90天前的数据
- 保留足够的数据用于分析
- 避免数据库过大影响性能

### 2. 数据备份
- 导出重要数据作为备份
- 清理前先导出再删除
- 建立定期备份机制

### 3. 查询优化
- 尽量使用索引字段查询（roomId, platform, uid）
- 避免大范围的时间查询
- 合理使用分页

### 4. 权限管理
- 仅授权人员可执行删除操作
- 清理旧数据需要二次确认
- 记录操作日志
