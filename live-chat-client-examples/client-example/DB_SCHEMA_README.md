# 数据库脚本整理说明

## 📋 整理概述

为了简化数据库维护，已将原有的多个 SQL 文件合并为一个统一的初始化脚本。

---

## 🔄 变更历史

### 之前（6个文件）
```
db/
├── init-mysql.sql                      # 平台配置表
├── live-data-collection.sql            # 直播数据采集表（4个表）
├── migration-add-api-key-config.sql    # API Key 配置表
├── migration-add-is-used-field.sql     # 入场记录表添加 is_used 字段
├── platform_display_config.sql         # 平台展示配置表
└── sys_user.sql                        # 系统用户表
```

### 现在（1个文件）
```
db/
└── schema.sql                          # 统一的数据库初始化脚本
```

---

## 📊 包含的表结构

`schema.sql` 包含以下 8 个表的完整定义和初始数据：

### 核心业务表（5个）
1. **platform_config** - 直播平台配置表
   - 存储各平台的直播间配置信息
   - 默认插入 4 个平台的初始配置

2. **live_danmu_history** - 弹幕消息记录表
   - 记录抖音、快手等平台的弹幕数据
   - 支持按房间、用户、时间查询

3. **live_room_stats_history** - 直播间统计数据表
   - 记录实时观看人数、点赞数等统计信息
   - 用于数据分析和趋势展示

4. **live_entry_history** - 用户入场记录表
   - 主要记录抖音用户的进入行为
   - 包含 `is_used` 字段标记是否已被使用

5. **live_gift_history** - 礼物赠送记录表
   - 记录礼物赠送详情（礼物名称、数量、价格等）
   - 支持礼物统计分析

### 系统管理表（3个）
6. **sys_user** - 系统用户表
   - 后台管理系统登录认证
   - 默认创建 admin 管理员账号（密码：admin123）

7. **platform_display_config** - 平台展示配置表
   - 控制前端页面显示哪些平台
   - 默认只启用抖音平台

8. **api_key_config** - API Key 配置表
   - 外部接口调用认证
   - 支持 IP 白名单和限流配置
   - 默认插入测试用的 API Key

## ✨ 特性说明

### 1. 幂等性设计
- ✅ 所有建表语句使用 `DROP TABLE IF EXISTS` + `CREATE TABLE`
- ✅ 所有插入语句使用 `ON DUPLICATE KEY UPDATE`
- ✅ 支持重复执行，不会产生错误

### 2. 模块化组织
脚本按功能分为四个部分：
- **第一部分**：数据库创建
- **第二部分**：核心业务表
- **第三部分**：系统管理表
- **第四部分**：验证查询

### 3. 完整的注释
- 每个表都有详细的字段注释
- 包含使用说明和执行命令
- 便于理解和维护

### 4. 自动验证
脚本末尾包含验证查询：
- 显示所有创建的表
- 统计各表的记录数
- 确认初始化成功

## ⚠️ 注意事项

1. **执行前备份**
   - 如果数据库中已有重要数据，请先备份
   - 脚本会删除已存在的表（`DROP TABLE IF EXISTS`）

2. **字符集设置**
   - 统一使用 `utf8mb4` 字符集
   - 排序规则：`utf8mb4_unicode_ci`

3. **JPA 同步**
   - 应用启动时 JPA 会自动同步表结构（`ddl-auto: update`）
   - 此脚本主要用于首次初始化和手动管理

4. **默认数据**
   - 脚本会自动插入所有必要的初始数据
   - 包括平台配置、管理员账号、API Key 等

## 🔍 常见问题

### Q1: 可以多次执行吗？
**A:** 可以！脚本支持幂等执行，多次运行不会产生错误。

### Q2: 会删除已有数据吗？
**A:** 是的，脚本会先删除表再重建。如果需要保留数据，请注释掉 `DROP TABLE` 语句。

### Q3: 如何只创建某个表？
**A:** 可以单独复制对应的 `CREATE TABLE` 语句执行。

### Q4: 默认密码是什么？
**A:** 
- MySQL 数据库：需要你提供 root 密码
- admin 账号：admin123（BCrypt 加密）
- API Key：test-api-key-123456

### Q5: 如何修改默认配置？
**A:** 执行脚本后，可以直接在数据库中修改配置数据，或者修改脚本中的 INSERT 语句。
